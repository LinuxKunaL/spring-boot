# Spring Boot Notes

My personal notes while learning Spring & Spring Boot, following a phased,
build-as-you-go roadmap.

📍 **[Full learning roadmap →](roadmap.md)**

## How this repo is organized

```
notes/   ← the actual notes (markdown), grouped by phase
code/     ← runnable example projects, grouped by phase
roadmap.md
```

- **Folders:** `phase-N-short-name` — lowercase, hyphens.
- **Note files:** `NN-topic.md` — the number is the reading order.
- **`README.md`** in any folder is its overview/index.

## Phases

| Phase | Topic | Notes |
|-------|-------|-------|
| 0 | Setup & Prerequisites | [notes/phase-0-setup](notes/phase-0-setup/) |
| 1 | Spring Core (IoC, DI, Beans) | [notes/phase-1-spring-core](notes/phase-1-spring-core/) |

> More phases get added here as I work through the roadmap.

## Example code

Runnable projects live under [`code/`](code/), mirroring the phase numbers
